**PlantScan3D** An open-source GUI for reconstructing plant 3D architecture from laser scans.

**PlantScan3D** is released under a **CeCILL** license, which is compatible to the **GNU GPL**.

## Installation

`openalea.plantscan3D` dependencies are [`pyqglviewer`](https://github.com/openalea/pyqglviewer), [`openalea.mtg`](https://github.com/openalea/mtg) and [`openalea.plantgl`](https://github.com/openalea/plantgl)

```bash
  mamba install -c openalea3 plantscan3d
```

## Use

```bash
  plantscan3d
```
